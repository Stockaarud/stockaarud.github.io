Qui fait Stockaarud

Stockaarud est né dans un CAARUD, pour répondre à un problème du quotidien : savoir ce qu’il reste au stock avant d’en manquer.

Il est conçu et maintenu par un médecin qui travaille dans une structure de réduction des risques à Marseille.

L’appli est gratuite et son code est public : chacun peut le lire sur GitHub. Pour nous joindre : stockaarud@proton.me.

Vos données restent chez vous

Aucune information sur les personnes accueillies : l’appli ne compte que du matériel.

Ce qui est enregistré
Le catalogue, les entrées et sorties de matériel (produit, quantité, activité, date), les commandes, les noms des fournisseurs et des associations partenaires. Les sorties ne portent aucun nom.
Où
Dans une base Supabase que votre CAARUD crée lui-même, à son nom. Le guide conseille la région Europe (Paris). Il n’y a pas de base commune.
Qui y a accès
Votre équipe, par le code ou le QR code que vous lui donnez, et vos responsables stock. Les règles sont appliquées par la base elle-même. Nous n’avons pas accès à vos données.
Donnée personnelle
Une seule : l’adresse e-mail du compte responsable stock, conservée dans votre projet Supabase.
Sauvegardes
Supabase gratuit ne garde pas de copie. L’appli télécharge une sauvegarde complète en un geste, et vous le rappelle.
Ce site
Il est hébergé par GitHub et ne reçoit aucune donnée de stock. Le formulaire de contact transmet votre message par le service Formspree.

Questions fréquentes

Ça marche sur iPhone et sur Android ?

Oui. Stockaarud s’ouvre dans le navigateur, sur téléphone comme sur ordinateur. Pour l’avoir comme une appli, ajoutez-le à l’écran d’accueil : dans Safari, Partager puis « Sur l’écran d’accueil » ; dans Chrome, le menu puis « Ajouter à l’écran d’accueil ».

Combien ça coûte ?

Rien. L’appli est gratuite, sans abonnement. La base de données est un projet Supabase gratuit, limité à 500 Mo de données et 1 Go de photos : c’est très au-delà de ce qu’un CAARUD utilise.

Et quand il n’y a pas de réseau ?

L’équipe continue de noter. Les saisies restent sur le téléphone et partent dès le retour de la connexion.

Faut-il créer des comptes pour l’équipe ?

Non. L’équipe entre avec un QR code ou un lien. Seul le responsable stock a un compte, avec un e-mail et un mot de passe.

Quelqu’un perd son téléphone ou quitte l’équipe ?

Dans Réglages, « Retirer l’accès de toute l’équipe » déconnecte tous les téléphones. Vous redonnez ensuite un nouveau code aux personnes qui restent.

On a plusieurs lieux de stockage ?

C’est prévu : un stock principal et, si besoin, des stocks intermédiaires (un local, une antenne) qui s’y réapprovisionnent.

Le projet Supabase s’est mis en pause ?

Supabase met en pause un projet gratuit resté 7 jours sans activité. Cliquez sur « Restore project » dans Supabase : aucune donnée n’est perdue.

On peut arrêter et récupérer nos données ?

Oui, à tout moment. L’appli exporte les mouvements, le catalogue et une sauvegarde complète. Pour tout effacer, supprimez votre projet Supabase : il n’existe aucune autre copie.

Une autre question ?

On vous répond, et on peut vous aider à l’installer.
